# Sakhi-AI-
Sakhi — a full-stack AI health companion app for rural Indian women. Voice-first, offline-capable, multilingual (6 languages), built for low-end Android on patchy networks. Features: AI symptom checker, pregnancy monitoring, voice assistant, facility finder, nutrition scanner, SOS system. Flutter + Firebase

## Meet the guides

Each feature has its own guide, an animal drawn as a person. See [docs/CHARACTERS.md](docs/CHARACTERS.md).
